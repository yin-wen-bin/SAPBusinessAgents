# 创建并验证一个只读 Agent，以计划行交货日期 2026-07-17 查询采购订单入库情况；采购组织、采购组、工厂、供应商和采购订单号保持可选，未提供时不添加相应过滤。

# Agent 详情（审阅稿）

名称：采购订单计划行入库状态查询

用途：按计划行交货日期查询采购订单入库情况，并在采购组织、采购组、工厂、供应商或采购订单号有值时进一步缩小范围。输出粒度固定为“采购订单 + 项目 + 计划行”。本内容不表示 Agent 草稿已生成、规则已实现或 Agent 已发布/激活。

## 输入

- 计划行交货日期：必填，按精确日期匹配；验证样本为 2026-07-17。
- 采购组织：可选；有值时匹配采购订单抬头的 PurchasingOrganization。
- 采购组：可选；有值时匹配采购订单抬头的 PurchasingGroup。
- 工厂：可选；有值时匹配采购订单项目的 Plant。
- 供应商：可选；有值时匹配采购订单抬头的 Supplier。
- 采购订单号：可选；有值时匹配计划行的 PurchasingDocument。
- 任一可选输入缺失、为空或仅含空白时，必须完全省略相应过滤条件，不得生成空值或等于 null 的过滤。

## 固定只读步骤

1. 从 A_PurchaseOrderScheduleLine 读取指定交货日期的全部计划行、计划数量及单位。
2. 按采购订单和项目两个字段成组关联 A_PurchaseOrderItem，读取工厂、物料、订单数量、是否预期收货、删除标识及 SAP 交货完成标识。
3. 关联 A_PurchaseOrder，读取采购组织、采购组、供应商和订单日期。
4. 按采购订单和项目成组关联 A_MaterialDocumentItem，读取全部相关物料移动、数量与单位、借贷方向、取消及冲销字段。
5. 按物料凭证年度和凭证号成组关联 A_MaterialDocumentHeader，读取过账日期、凭证日期及创建时间。

所有 SAP 步骤必须保持 GET-only，不得创建、修改、过账、批准或删除 SAP 数据。
