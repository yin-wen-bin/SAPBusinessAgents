# CO · 管理会计 / Controlling

区分成本中心费用、预算滚动预测、内部订单/WBS、CO月结与生产订单成本分析。生产订单成本差异比较计划、目标与实际，不再以通用物料价格分析描述。

Distinguish cost-center expense, rolling forecasts, internal order/WBS, CO closing and production-order costs. Production-order variance compares planned, target and actual cost, not generic material pricing.
