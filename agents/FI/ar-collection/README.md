# 应收账款催收助手 1.2.0

这是待真机验收的候选版本。它批量读取客户应收；当前基准日使用客户催收主数据，历史基准日使用独立验收的已执行催收事件 Skill，重建截止日账龄，并为每个项目确定是否需要处理、处理原因、建议动作及 SAPBusinessAgents 处理优先级。

业务报告把“需要处理的催收工作清单”与“全部未清应收明细”分开。未到期普通应收保留在明细中并标记为“仅监控”，不会进入待办清单。工作清单同时生成 `ar-collection-worklist.csv`。

边界：处理优先级不是 SAP 原生催收优先级；不读取银行来款，不发送催款通知，不执行清账或过账；历史客户催收主数据快照仍不评估，不能用当前主数据代替。
