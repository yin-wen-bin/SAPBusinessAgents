# Codex App 内的自动测试

在 SAPBusinessAgents 项目聊天中使用 `$sapba-auto-test`，或输入“测试 SAPBusinessAgents”。当前聊天的主 Agent 直接使用已启用的 Codex 工具，不启动额外 AI Runtime，也没有独立测试网站。

安装仓库中的 Skill 和受控测试 MCP 工具：

```powershell
.\.venv\Scripts\python.exe -m sap_business_agents_test_agent install --register-mcp
```

安装保留现有 Codex 配置；遇到同名且不同配置的 MCP 或被手工修改的技能文件时报告冲突。安装后开启新的项目聊天或重新加载工具配置。源码位于 `skills/sapba-auto-test`；安装目录位于本机 Codex 技能目录。

聊天内勾选功能，生成并查看脚本后点击“开始测试”。默认选择自由查询、工作流、Agent 管理；固定业务 Agent、岗位匹配、插件、配置和历史/证据也可选。卡片桥接不可用时，将卡片给出的操作复制到当前聊天即可。

自动测试读取当前代码并保留未提交修改。修复候选与生命周期测试的临时产品副本分开；临时发布、启停或删除不会修改原目录。SAP 使用现有账号可读范围内的有界只读证据；外部发送、账号变更与 SDK 替换使用模拟或专用临时环境。

每轮先跑完所有可执行用例，再聚合错误和集中修复。默认最多三批，重测失败项与影响范围，最终完整复核所选功能。通过回归门禁的累计补丁自动应用到本地；遇到后续用户修改则保留补丁和冲突说明，不自动提交或推送。

运行状态和证据保存在忽略目录 `.local-data/auto-test`。可在聊天中要求“停止”“继续上次测试”“重测失败项”或“查看报告”。报告区分真实 SAP、离线、模拟和未覆盖操作；离线回归种子不代表真实业务闭环已通过。

辅助工具也可通过 `python -m sap_business_agents_test_agent --help` 查看；智能编排始终由当前聊天完成。MCP 仅暴露功能发现、计划保存、任务开始/状态、受控 SAP 读取及取消。
