# 外部共享认证缓存变化后的自动收尾

API 生命周期每 5 秒在后台核对 WorkBuddy 的本机认证缓存元数据。GET 不触发探针、不改认证；不读取或复制凭据正文。未登录、撤销、身份来源／站点／执行环境变化不能通过观察文件恢复资格。

有既有确认绑定且只发生缓存变化时，复用现有单飞官方只读身份复核及原 30 秒预算。活动作业、SDK 租约、维护和清理阻碍解除后继续；同一观察版本真正复核失败后不循环重试。新缓存版本可以发起新的核对，显式手动核对入口保留。退出、登录、换账号、模型探针及 SAP 查询均不由观察器触发。

同账号确认不递增认证绑定修订或清空模型兼容证据；真正账号变化仍使旧任务绑定失效。未确认前原认证、权限、Schema和派发门禁保持失败封闭。配置及历史台账不为恢复可用性而改写。

设置页将有上次成功记录但缓存待核对的状态显示为“认证待核对（不是已退出）”，不以登录按钮暗示必须重新登录。自动核对采用只读状态轮询，遇失败停止，页面隐藏暂停；成功后停止轮询。确认退出、认证失效和检查失败保持各自含义。Codex 后台不启用此观察器。

部署维护标记存在时暂停自动观察派发，避免切换过程中启动新认证写入者。API 退出取消所属观察任务和现有认证任务，沿用原清理窗口，不恢复旧作业。

离线测试：`tests/test_workbuddy_external_auth_sync.py` 及原认证回归；前台测试：`site/tests/external-auth-sync.test.mjs`、`site/tests/external-auth-sync.browser.mjs`。真实登录和业务调用不是离线通过的证明。
