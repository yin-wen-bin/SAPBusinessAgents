`runtime_environment.py` 现在允许显式维护阶段附加官方制品证明，但必须同时满足：

- 制品哈希在冻结代码的精确审核列表中；调用方自行提交哈希不构成信任。
- 每次核验完整制品哈希、包身份、成员清单、成员内容及本机对应文件。
- 仅对“原包实际内容与其原始 RECORD 自身不符”的同一记录采用来源证明；本机记录或文件与原包不同仍拒绝。
- 缺证、制品变化、版本不符、重复成员、路径越界、链接、重新捕获后的文件变化等仍拒绝。

独立候选环境只在其依赖锁仍指向相同版本、相同审核哈希时传递证明，并重新核对候选中的全部成员，不复制旧环境的合格结论；依赖版本变化不能继承旧证明。该路径仅在今后用户明确发起真实更新时使用，本次没有执行真实安装。
