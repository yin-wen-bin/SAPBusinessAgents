# 系统配置按需读取

系统默认仅在 Runtime 导航标记；顶部重复摘要及常驻刷新按钮已移除。更新详情入口只保留在所属 SDK 高级维护中，导航仅显示简短更新中／需处理提示。

首次进入读取一次轻量导航列表；用户选择 SDK、点击已选 Tab、浏览器前进后退返回面板时，使用现有 GET 的可选 `provider_id` 参数读取当前 SDK。定向结果合并到原导航缓存，不删除其他 SDK。未知 Provider 返回 404；未携带参数保持原列表语义。

普通状态没有持续轮询。明确的后台展示读取可在一次事务内补读：总计最多 10 秒、4 次 GET，退避 1／2／5 秒；失败、切换 SDK、隐藏页面或达到上限即停。单纯过期或待核对不会启动补读，必要时在对应区域提供“重试读取”。只显示页面上次读取时间，不冒充认证检查时间。

SDK 更新弹窗可见时仅追踪所属操作，每 2 秒 GET；关闭、收起、Esc、隐藏页面或离开 Runtime 分区暂停读取，不取消后台更新。重新打开后核对原 requestId／operation_id；临时断连最多按原 1／2／5 秒退避核对 120 秒，之后停读。生效后只对所属 SDK 刷新一次相关展示，不能用版本相同或 POST 成功代替激活确认。

内部渲染与用户读取事件分离。状态通知、展开高级维护及空闲页面恢复可见均不发起新的展示读取。表单、未保存输入、展开状态及焦点保留；迟到响应和绑定变化沿用严格保护。登录和认证后台机制、安装、模型兼容、权限及实际准入不变，展示不能授权。

最初交付离线候选和模拟回归；2026-10-30 已按后续明确授权，完成原维护、接入审核和 GET 验活流程后受控上线。没有调用真实模型／SAP、升级 SDK、修改配置或历史 PASS。

本次上线从实际已激活版本派生：后端仅修改展示 GET 的 Provider 筛选，前台仅更新中英文设置页及其内容寻址资源；其他页面及无关工作区修改未夹带。精确目标后端 86 项、浏览器模拟 52 组通过，原执行组件和模型协议不变，直接复用既有有效接入认证，没有追加或改写证书。951 个受保护文件和 13 张历史表对照一致，默认 Runtime、SDK／CLI／worker 及原环境绑定不变。
