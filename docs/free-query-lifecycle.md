# 自由查询页面生命周期与并发

## 使用行为

- 新查询使用标签页内的归属标记。停止并返回、浏览器后退、站内或外部跳转会请求取消所属查询，不取消其他查询。
- “另开查询”在新标签页创建独立查询；原标签页保持运行。最多10项自由查询执行，超过上限排队。
- 页面刷新恢复原归属标记，不重发业务请求；只切换标签页、同页URL更新或另开标签页不会取消。
- 页面不发送心跳，服务端不再按页面失联时间取消。关闭浏览器、异常退出、断网、休眠或取消请求未送达时，由原有任务超时兜底。
- `pagehide`只关闭页面连接，不直接取消，以免把刷新误认为离开。明确导航取消使用幂等接口与`keepalive`请求。
- 重新打开页面按原运行ID和会话恢复查看进度、结果或取消状态，不自动创建新运行或继续已取消任务。纯历史查看不自动接管归属；用户主动发起反馈或续查时记录当前页面归属。
- 归属标记存放在`sessionStorage`，没有过期时间，不是SAP授权；兼容已有标签页中的旧标记。

## 停止与隔离

服务端先持久化取消意图，撤销所属工具会话，再停止SDK与工具任务。HTTP断开不放弃已受理的取消。
清理最多10秒，确认后才标为已取消；未确认保留`cleanup_pending`和占用的执行容量，不自动重试业务请求。
已发出的SAP只读请求只能尽力中止，不能保证撤回SAP服务端处理；迟到结果不得应用。

查询、会话、证据、授权、工作目录、模型绑定和Windows所属进程分别隔离。同一查询会话的续查及反馈仍串行。
普通自由查询共享WorkBuddy容量；其他WorkBuddy业务保留独占访问，等待独占者时不继续插入新的共享查询。
已知本进程派发窗口只按原始task/attempt、Runtime、环境、协议、截止时间和宿主创建标识核对；未知派发或清理记录仍阻断。

## 配置及接口兼容

`SAPBA_LOCAL_FREE_QUERY_WORKERS`默认10；`SAPBA_MAX_CONCURRENT_SAP_GETS`默认10。
SAP读取槽由本机API所有查询及Provider共享，不是每项查询各10个；单项读取范围、调用次数与预算不变。

新前台不再提交`pageLeaseId`或调用续租接口。旧创建和反馈请求中的`pageLeaseId`仅兼容接收，执行时忽略。
`PUT /api/runs/{run_id}/view-lease`保留兼容：核对运行存在后返回`{"enabled":false}`，不修改运行或历史状态；不存在的运行仍返回404。
状态GET中的`page_lease`统一为`{"enabled":false}`，保留取消收尾和排队位置。历史租约JSON和取消事件不清除，不再用于调度或反馈控制。
手动停止及明确离页仍使用原有幂等取消接口。刷新、重连、历史查看与提交结果未知时只读取已有记录，不自动提交或执行。

## 验证和上线

使用模拟Runtime、MockTransport及不包含SDK的本地协议worker验证10路并行、排队、单项取消、任务超时、失联不取消、旧接口兼容、恢复查看、进程清理与浏览器行为。
查询生命周期及调度由源码冻结、独立控制层测试保护；SDK依赖只新增完整的`runtime_capacity.py`组件。
模型协议、SDK/CLI与worker内容未变，不新增模型探针、不重跑15项业务评测，不改写历史PASS。
SDK接入认证只能基于原始真实通信材料及目标基础设施测试追加审核，不把离线测试登记为业务PASS。

上线须在相关任务、旧写入者及清理进程退出后持维护锁切换。保留历史取消记录和新证据，不恢复或重跑已终止任务。回退到含租约扫描的版本会重新解释旧租约状态，须在无活动任务时操作，不能直接替换活动写入者。
