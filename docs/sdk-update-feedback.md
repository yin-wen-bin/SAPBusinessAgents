# SDK 更新进度与结果反馈

系统配置页共用更新进度弹窗，适用于 Codex 和 WorkBuddy。确认更新后立即显示 SDK、原版本、目标版本、真实阶段、耗时和下载字节进度；不估算整体百分比或完成时间。

- 收起、关闭和 Esc 只关闭弹窗，不取消维护操作。SDK 导航及高级维护保留重新打开入口。
- 准备完成、已安装、待审核、待重启、生效、失败、回退及结果未知分别展示。只有后端激活结果、清理确认与实际版本一致，才展示“已生效”。
- 页面按 Provider、原 requestId 和 operation_id 核对操作。刷新或断连不重复安装、恢复或派发；历史记录没有请求标识时不猜测关联。
- API 临时断连按 1／2／5 秒退避，仅 GET 核对原操作，最多自动重连 120 秒。之后保留原操作和手动读取入口。页面隐藏暂停轮询，恢复可见时重新核对。
- 每个已确认生效的操作只自动失效并局部读取一次相关展示。未保存模型及推理输入、Tab 和展开状态保持；绑定变化时要求用户核对，不静默应用。页面读取失败与更新失败分别展示。
- 原始安装日志不进入弹窗。安全错误码及失败阶段放在默认折叠的诊断中；完整后台记录不变。

没有新增更新、安装、认证、模型兼容、激活或回退算法、公开接口及数据库表。WorkBuddy 仅兼容补充请求关联字段；Codex 仅补齐响应投影。状态 GET 不安装 SDK、不触发登录、兼容探针或 SAP。

## 离线验证

`site/tests/settings-model-picker.test.mjs` 覆盖共享状态映射、严格关联、重连时限、单请求和弹窗行为。`site/tests/sdk-activation.browser.mjs` 使用不可变前台构建、拦截全部网络及模拟 API，覆盖两种 Provider、中英文、1440／690／550／390px、响应丢失、刷新恢复、清理待确认、API 断连及生效后的局部读取失败。

后端定向回归覆盖更新幂等、请求字段、环境激活及原安全门禁；模拟测试不是实际升级、认证或业务 PASS。上线仅 GET 验活，不通过真实更新作为测试。
