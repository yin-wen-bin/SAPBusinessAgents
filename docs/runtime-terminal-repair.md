## 本次只读回放

案例为 `run_1768d6b67a8845d4`，国内站、`glm-5.3-flash`、SDK 0.3.247、CLI 2.141.0。
保存事件显示报告工具已通过，但四次原生终态候选中的两个可空枚举持续非法，前两次还有 presentation 错误。
四次拒绝反馈的摘要均与实际观察结果匹配；最后 SDK 返回 success，但 structured_output 不存在。
运行没有达到1800秒硬截止，所属进程清理已确认，不能归因为401、SAP超时或清理挂起。

安全记录只保留类型、约束、摘要和消息计数，没有保存非法字符串原值和原始推理。
因此回放是安全形状重建，不是原始候选逐字节重放。模型为什么持续产生非法枚举，不能由离线测试证明。
同版本官方CLI来源代码显示：Schema由 json-schema 参数传入，格式化工具成功执行后才设置捕获结果；SDK Python解析器直接读取 structured_output。
没有发现 Python 解析器把有效终态丢掉的依据；同版本JavaScript来源不能代替对二进制内部每个实现细节的证明。

## 共享规则

报告业务校验、完整终态Schema、授权和证据规则不变。两个澄清字段增加说明元数据，不改变枚举、必填、可空或额外字段约束。
共享 terminal contract 从冻结Schema生成允许值、期望类型、字段说明和安全路径，不由SDK适配器猜测字段含义。
非法值仍由模型自行修改；平台不补字段、不转换字符串null、不删除未知字段、不把已验证报告替代为完整终态。

终态候选按真实提交计数，消息观察与幂等重传不重复计数；同一提交ID换正文拒绝。
复用共享报告纠错算法：连续三次无实质进展停止所属作业；实际消除约束错误属于进展，不能把本案例四次尝试误报为四次完全无进展。
收敛只覆盖完整终态格式化，不限制正常调查、编辑、本地测试、取证工具数或SDK全局轮次。
没有新增外部读取、模型调用、重试作业、预算或权限。

## 必要SDK差异

Codex继续使用原生输出Schema和已验证报告提前收尾，不增加原生格式化工具或一次额外总结调用。
WorkBuddy通过版本化握手声明终态协议能力；新宿主不能默默在旧worker上退回旧纠错路径。
原生hook、候选消息观察、最终ResultMessage分别编码，只有hook的新提交推进纠错状态。
worker仅转换协议；权威检查、纠错反馈和停止决定来自平台共享组件。
拒绝反馈到达但原生工具is_error=false，不能覆盖平台拒绝或当作成功。
有效候选仍不是有效终态；宿主还必须收到经过校验的原生终态，并核对其与最终result内容一致。
空终态保留此前候选的具体约束错误，不能被根路径null错误覆盖，原始失败和清理结果分别保存。

## 正式验收的非交互终态

正式Campaign冻结案例输入，发现缺失后中断并返回案例设置，不会在基线运行中接管新的安全引用输入。因此共享终态Schema在正式模式保留`input_kind`和`input_field`两个必填字段，并将其类型收紧为`null`、枚举收紧为`[null]`；缺信息仍可返回`waiting_input`和明确的问题。不能因此猜测缺失信息或放开读取。

普通自由查询仍使用原可空字符串枚举，保留安全引用澄清能力。Codex与WorkBuddy正式模式同时采用该Schema和提示；这是明确的正式终态表达变化，不宣称Codex的所有输出参数完全不变。其他字段、报告、投影、证据、范围、权限、预算以及Codex验证后提前收尾与WorkBuddy原生终态要求均保留。SDK、CLI和worker不因该业务模式约束而更换。

共享Harness将有明确协议身份的原生终态缺失/非法/纠错停滞保存为独立终态原因；Campaign优先透传此原因与原候选的安全字段路径，不再把`capability_unavailable`一律折叠为环境中断。没有终态仍不能生成PASS，清理未确认仍保持阻断。历史失败报告不改写。

报告未知字段反馈不回显模型生成的未知键名或值，而是返回可信Schema中的父对象位置、完整允许字段和明确删除未声明字段的动作。枚举错误返回权威Schema的允许值。平台不代替模型执行删除、重命名或值修正，原候选仍被拒绝。工具报告可省略不适用的合法可选字段；成功的规范报告仍负责完整终态默认值交接。两种SDK共用此反馈，不改变业务检查、取证范围或执行预算。

可空对象终态失败时保留原`anyOf`错误，并在JSON类型唯一对应一个分支时展开该分支内部的可信字段错误；多对象分支存在歧义时不猜测。诊断去重先于50项上限截断，避免重复必填错误耗尽反馈预算。嵌套元数据仍只来自冻结Schema，不回显业务值或未知字段。报告自定义形状校验仅透传白名单内的检查器固有原因（例如无展示内容、表格列数不一致），不透传任意异常文本。不改变校验器、原生终态要求、收敛阈值或任务预算。

## 部署边界

本轮在隔离候选完成，只读原始运行和受保护记录；没有修改运行中API、安装环境、模型配置或历史PASS。
worker变更后必须通过正常不可变release流程生效，保留SDK、CLI及依赖锁。不得覆盖旧worker或改写旧安装摘要。
接入认证和模型协议摘要将按实际组件变化；新增组件列入现有完整组件依赖，不修改摘要算法或伪造承接。
后续上线、接入认证审核及必要轻量兼容检查必须另按维护与授权流程完成。离线通过不等于真实模型已经修正非法输出。
