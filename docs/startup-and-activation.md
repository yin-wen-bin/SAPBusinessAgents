# 普通启动与修改后激活

## 首次安装

安装README声明的Python和前端依赖后，没有部署历史的新目录会在首次普通启动时完成初始化：校验本机`.venv`、冻结源码与环境、执行原接入审核、构建和探测前端，再在维护锁及原切换日志保护下启动并登记健康的API/前端组合。不复制其他机器的数据，不自动安装依赖，不调用SDK模型或SAP，不授予业务执行资格。

已有当前记录继续走原薄引导；损坏记录、历史版本、已有业务数据库、孤立维护标记和未完成切换不会被当作新安装覆盖。首次准备失败保留`startup/initialization.json`及原诊断，可在没有未收尾切换时重试；首次切换失败仅清理本次确认归属的进程和部分指针，保留源码、数据库与日志。崩溃后的首次切换也使用原`recover-switch`恢复，确认目标已健康则完成登记，否则只退回未激活状态，不要求不存在的历史回退版本。

普通启动只在被调用期间检查更新，不安装常驻监控。验证器登记了与当前源码完全一致的新版本时，普通启动和显式重启都会自动等待任务空闲，构建前台并通过原代码激活流程切换、验活和核对版本。没有待激活更新时，服务健康就直接打开，未运行就只启动缺失的服务；不重复测试、构建或执行 SDK 接入审核。

验证记录与当前源码不一致时明确阻断更新并提示重新验证；没有记录的工作区修改不会被默认为已验证。启动时会提示这些改动尚未生效，保留已有激活版本。已完成的更新不因再次启动或后来正常发布 Agent 前台而重复应用，也不覆盖主动回退。

## 入口

- `start-sap-business-agents.cmd`：先读取已验证更新登记。有匹配的新版本则自动进入原受控激活；否则核对引导代码、解释器和服务绑定，打开或补启当前组合。
- `restart-sap-business-agents.cmd` / `-Restart`：同样自动应用匹配的已验证更新；没有更新时强制重启当前组合。
- `-RestartSiteOnly`：只重启当前前台；API必须已按当前绑定运行。
- `-RebuildSite`：显式构建及激活前端修改，沿用构建校验、私有端口验活、维护锁和回退；不是普通刷新。
- `-Dev -SitePort 4322`：连接已运行的已激活API，单独启动开发前端；不改写正式指针，不接管正式端口。
- `service-startup.py activate-code --target-record <交接文件>`：仅供已授权上线任务调用。交接文件关联 `base`、`target`、`base_site`、可选目标 `site` 和 `tested_source_digest`；它只定位已测试组合，不授予接入认证或业务资格。源码激活不得改变Python环境，SDK激活仍使用原 `activate-sdk`。

当前／回退记录、维护屏障和 `startup/pending-switch.json` 继续是原有权威记录，不增加第二套部署状态机。除上述确认全新安装的初始化外，没有有效当前记录或运行绑定不明时明确阻断，不猜测最新版、不自动登录或换环境。未完成切换不允许启动缺失组件；已健康运行的页面可以打开，但保留明确维护提示和原执行屏障。

没有待激活更新时，普通启动不枚举整机监听端口，不创建维护标记、切换日志或候选，不运行安装遍历、SDK接入审核和历史任务扫描；两个健康GET及所属进程身份足以复用现有服务。缺失服务启动时仅使用部署锁防止重复双击，端口已占用但健康未确认时不自动杀进程或重启。API自身原有的启动恢复、归档和依赖验证仍执行一次；真实查询的完整认证、权限、范围、Schema和证据门禁不变。

如果此前已有未收尾的维护操作，健康服务仍可打开并明确提示待恢复，但不能因此移除维护屏障；未运行的服务继续要求先安全恢复。普通启动不承担旧部署恢复，更不会直接删除日志后冒充更新成功。仅更新同一组合的进程PID/创建标识，不改变源码、环境、SDK或业务资格。

## 完成修改的收尾

服务切换通过 [MCP 维护协议](mcp-maintenance.md) 暂停新调用并排空已接收调用，保留 stdio 连接。原有任务、源码、环境、进程身份、验证和回滚门禁继续适用；未知写入者和没有协议的旧 MCP 仍会阻断。首次安装该协议需重新加载一次旧 MCP，之后兼容服务更新无需关闭连接。

自动测试 Agent 的累计补丁通过最终复核并回写后，校验完整代码输入与候选一致，自动登记 `.local-data/startup/verified-update.json`。报告分别展示“测试通过／文件已回写”“已登记待启动激活”和正式服务版本；登记本身不代表正式 API 已切换。无法登记时保留具体原因，既不撤销成功的文件回写，也不冒充已激活。

对于直接开发或手工更新代码，开发／测试阶段运行以下一次性验证命令，成功后自动登记新版本。普通用户下一次运行原启动脚本即可完成激活，不必手工填写交接 JSON：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B scripts\startup-update.py verify --root D:\SAPBusinessAgents
```

`--test tests/test_名称.py` 可以重复追加本次修改的相关离线回归文件，不替换必跑的启动、切换、恢复、更新及测试 Agent 登记回归。验证绑定源码、前台输入、测试文件、JUnit 与日志哈希。失败、空测试、并发修改、证据变化均不登记成功。验证不调用模型或 SAP，也不授予业务验收资格；相关业务功能仍由其独立用例验证。

启动消费验证登记后，使用当前 Python 环境冻结 API、构建前台并产生原 `activate-code` 交接记录。切换仍由现有控制器负责维护锁、再次空闲检查、进程归属、实际源码／环境／前台绑定及配对回退。并发启动只对同一登记串行消费；等待仅存在于这次启动进程中，Ctrl+C 不停止现有业务任务。

授权范围内的候选从当前版本派生，不混入其他未提交修改。冻结后对同一内容回归并审核接入证据；每5秒等候空闲，期间不持部署锁。切换前在锁和维护屏障下再次核对任务、认证维护、旧写入者、清理、原组合和配置；只停止归属及创建时间一致的进程。

新进程健康、实际源码与环境绑定、前端和最终一致性确认后才提交激活记录。失败恢复配对源码及环境；前端独立失败只回退前端。证据不足停留在未激活。保存代码或运行验证本身不切换服务；下一次用户调用启动器时才消费匹配的验证登记。

## 缓存与完整性

主API及平台Python子工具显式使用 `-B`；引导模块直接编译已核对源码，不读取邻近字节码。`-B`不阻止读取已有缓存，因此完整归档清单检查仍拒绝额外 `.pyc`、未知文件、链接及原文件变化。

维护入口 `recover-bytecode` 仅恢复当前归档：先验证原Manifest和原文件，额外项必须是对应原源码、具有合法头的常规缓存。确认空闲并持维护锁后，将缓存按原相对路径移动到此次恢复日志的 `quarantine`，保留时间及哈希记录。不能修改Manifest、重算信任摘要或删除原证据。异常内容继续阻断。

热打开只检查实际服务绑定和进程，不代表重新完成执行准入。普通冷启动不再在启动器中重复完整归档、依赖和接入审核；API进程保留自身的来源/环境验证及必要恢复。显式激活仍保留原完整检查和维护屏障；不跨请求或跨进程缓存执行授权。

Windows热打开以原生只读接口取得当前命令行和创建时间，与已保存身份及实际健康绑定核对；原生查询不可用时回退到原严格CIM核对。受控停止、旧写入者检查及维护锁规则不变，不保存新的跨请求身份授权缓存。

受控激活通过 Windows 原生 `OWNER_PID_LISTENER` 端口表获取 IPv4／IPv6 监听进程，避免部分主机的 `netstat` 漏报。接口不可用时回退原命令；端口归属有歧义或进程身份未知时仍拒绝停止。

## 验证与操作边界

使用模拟SDK和隔离状态验证启动、重启、激活、崩溃恢复与回退；不得为了启动调用真实模型、SAP或15项业务评测。上线仅GET验活。计时包含最终一致性及日志落盘；热启动至少20次，目标P95不超过3秒，冷启动和空闲等待另计。

本轮不升级SDK、CLI或worker，不改变账号、模型、预算和权限，不改写历史PASS，不提交或推送。交付证据位于 `.local-data/launcher-active-20261029/`；最终上线与实测结果另见该目录报告。

2026-10-29已受控上线。最终275项冻结回归通过；正常Windows账户20次真实批处理热启动P50为902.07毫秒、P95为988.99毫秒。该指标仅指已有服务的热打开，不表示冷启动或版本激活也在1秒内完成。交付详情见 [上线与性能报告](startup-and-activation-verification.md)。

2026-10-31恢复上述简单普通启动路径，旧维护入口保持独立。本次103项相关离线回归通过（包含冷启动模拟），20次真实批处理热打开全部成功，P50为2551.93毫秒、P95为3961.89毫秒；此为本次机器实测，不与此前不同运行条件的热路径混算，也不冒充真实冷启动耗时。测试未启停正式服务或调用SDK、模型、SAP。上次同版本启动登记失败，经原进程归属、空闲、来源及环境完整性审核后完成登记，原切换日志和维护标记保存于 `.local-data/startup-simple-20261031/recovery/`，未改变源码版本、环境或业务资格。详细测试和耗时记录位于 `.local-data/startup-simple-20261031/`。
